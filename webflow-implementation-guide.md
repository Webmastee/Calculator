# CyberForge X - Swiper.js Product Slider Implementation Guide

## Overview
This guide will help you implement a dynamic product slider similar to StarForge Systems' second section using Swiper.js in Webflow. The slider will populate product data dynamically when clicked, including specifications, pricing, and performance metrics.

## Features
- ✅ Dynamic product data population on click
- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Smooth animations and transitions
- ✅ Auto-play with pause on interaction
- ✅ Keyboard navigation
- ✅ Touch/swipe support
- ✅ Performance metrics display
- ✅ Technical specifications
- ✅ Pricing with sale indicators

## Step 1: HTML Structure in Webflow

### Create the Section Structure:
1. Add a new **Section** to your page
2. Add a **Container** inside the section
3. Create the following structure:

```
Section (class: "product-section")
└── Container
    ├── Div Block (class: "section-header")
    │   ├── Heading H1 (class: "section-title") - Text: "Gaming PCs"
    │   └── Paragraph (class: "section-subtitle") - Text: "Discover our high-performance gaming systems"
    │
    ├── Div Block (class: "swiper product-swiper")
    │   └── Div Block (class: "swiper-wrapper")
    │       └── [Slides will be generated by JavaScript]
    │
    └── Div Block (class: "product-details")
        ├── Div Block (class: "product-info")
        │   ├── Heading H2 (id: "product-name")
        │   ├── Span (class: "series-badge", id: "product-series")
        │   ├── Div Block (class: "pricing")
        │   │   ├── Span (class: "current-price", id: "current-price")
```

```html
// Generate slides
function generateSlides() {
    const swiperWrapper = document.querySelector('.swiper-wrapper');
    swiperWrapper.innerHTML = '';

    productData.forEach((product, index) => {
        const slide = document.createElement('div');
        slide.className = 'swiper-slide';
        slide.setAttribute('data-product-id', product.id);
        
        slide.innerHTML = `
            <div class="product-card">
                <img src="${product.image}" alt="${product.name}" class="product-image">
                <div>
                    <div class="product-series">${product.series}</div>
                    <h3 class="product-name">${product.name}</h3>
                    <div class="product-price">
                        ${product.currentPrice}
                        <span class="original">${product.originalPrice}</span>
                    </div>
                </div>
            </div>
        `;
        
        swiperWrapper.appendChild(slide);
    });
}

// Update product details
function updateProductDetails(productId) {
    const product = productData.find(p => p.id === productId);
    if (!product) return;

    // Update main product info
    document.getElementById('product-name').textContent = product.name;
    document.getElementById('product-series').textContent = product.series;
    document.getElementById('current-price').textContent = product.currentPrice;
    document.getElementById('original-price').textContent = product.originalPrice;
    document.getElementById('product-description').textContent = product.description;

    // Update specifications
    const specGrid = document.getElementById('spec-grid');
    specGrid.innerHTML = '';
    
    Object.entries(product.specs).forEach(([key, value]) => {
        const specItem = document.createElement('div');
        specItem.className = 'spec-item';
        specItem.innerHTML = `
            <span class="spec-label">${key}</span>
            <span class="spec-value">${value}</span>
        `;
        specGrid.appendChild(specItem);
    });

    // Update performance data
    const performanceGrid = document.getElementById('performance-grid');
    performanceGrid.innerHTML = '';
    
    product.performance.forEach(perf => {
        const perfItem = document.createElement('div');
        perfItem.className = 'performance-item';
        perfItem.innerHTML = `
            <div class="performance-game">${perf.game}</div>
            <div class="performance-fps">${perf.fps}</div>
            <div class="performance-label">${perf.label}</div>
        `;
        performanceGrid.appendChild(perfItem);
    });
}

// Handle slide clicks
function handleSlideClick(event) {
    const slide = event.currentTarget;
    const productId = slide.getAttribute('data-product-id');
    
    if (productId) {
        updateProductDetails(productId);
        
        // Find the index of clicked slide and go to it
        const slides = document.querySelectorAll('.swiper-slide');
        const slideIndex = Array.from(slides).indexOf(slide);
        swiper.slideToLoop(slideIndex);
    }
}

// Handle swiper slide change
swiper.on('slideChange', function () {
    const activeSlide = document.querySelector('.swiper-slide-active');
    if (activeSlide) {
        const productId = activeSlide.getAttribute('data-product-id');
        if (productId) {
            updateProductDetails(productId);
        }
    }
});

// Initialize everything
document.addEventListener('DOMContentLoaded', function() {
    generateSlides();
    
    // Set initial product (first one)
    updateProductDetails(productData[0].id);
    
    // Add click listeners to slides
    setTimeout(() => {
        const slides = document.querySelectorAll('.swiper-slide');
        slides.forEach(slide => {
            slide.addEventListener('click', handleSlideClick);
        });
    }, 100);
});

// Handle window resize
window.addEventListener('resize', function() {
    swiper.update();
});
```

## Step 4: Customization Options

### Color Scheme
You can easily customize the color scheme by modifying the CSS variables in the `:root` selector:

```css
:root {
    --primary-color: #your-primary-color;
    --accent-color: #your-accent-color;
    --background-dark: #your-background-color;
    --background-card: #your-card-background;
}
```

### Product Data
Modify the `productData` array in the JavaScript to include your actual products:
- Update images with your product images
- Modify specifications to match your products
- Adjust pricing and performance metrics
- Add or remove products as needed

### Swiper Settings
Customize the slider behavior by modifying the Swiper configuration:
- `autoplay.delay`: Change auto-play speed
- `slidesPerView`: Adjust number of visible slides
- `spaceBetween`: Modify spacing between slides
- `breakpoints`: Customize responsive behavior

## Step 5: Testing and Optimization

1. **Test on all devices**: Mobile, tablet, and desktop
2. **Verify click functionality**: Ensure product data updates correctly
3. **Check responsive behavior**: Confirm slider works on all screen sizes
4. **Optimize images**: Use appropriate image sizes for better performance
5. **Test loading speed**: Ensure JavaScript loads properly

## Troubleshooting

### Common Issues:
1. **Slider not appearing**: Check that Swiper CSS and JS are loaded
2. **Click events not working**: Ensure event listeners are properly attached
3. **Responsive issues**: Verify breakpoint settings in Swiper config
4. **Performance problems**: Optimize images and reduce JavaScript complexity

### Debug Steps:
1. Open browser console and check for errors
2. Verify all required elements have correct IDs and classes
3. Test product data structure for completeness
4. Ensure Webflow elements match the expected HTML structure
